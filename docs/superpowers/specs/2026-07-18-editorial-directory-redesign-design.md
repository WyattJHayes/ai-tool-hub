# AI Tool Hub 编辑型目录重设计

## 背景与目标

当前生产首页叠加了紫蓝渐变、网格、光晕、玻璃拟态、胶囊按钮和悬浮动效，首屏真实工具密度不足，呈现出明显的生成式 SaaS 模板感。本次重设计把产品定位从“AI 主题展示页”调整为“长期维护的工具目录”，让用户进入页面后可以立即搜索、浏览和比较工具。

成功标准：

- 桌面和移动端第一屏都能看到真实工具或场景入口。
- 页面只使用一种品牌强调色，不再使用紫蓝渐变、粒子、网格和大面积发光。
- 首页搜索、分类、卡片和导航形成统一、紧凑的工具型界面。
- 搜索建议不重复，移动端不显示桌面快捷键提示。
- 保留现有数据、路由、收藏、比较、登录和跟踪行为。

## 方案选择

### 方案 A：仅清理装饰

保留现有深色结构，只移除粒子和部分渐变。改动小，但仍会保留大 Hero、玻璃卡片和同质化信息结构，无法解决模板感的根因。

### 方案 B：Ant Design 风格换肤

使用标准后台组件语言统一控件。实现风险较低，但容易从“AI 模板”变成“企业后台模板”，也不适合强调策展和发现的目录产品。

### 方案 C：编辑型工具目录（采用）

使用暖白页面、墨色文字、克制的绿色强调色和扁平边框。压缩首屏，优先展示具体工具、用途和筛选条件。该方向最符合用户“去 AI 味”的目标，也能保持现有功能边界。

## 视觉系统

- 背景：暖白 `#F6F7F4`，内容面 `#FFFFFF`，深色文字 `#171A17`。
- 强调色：单一墨绿 `#176B4D`；红、黄只用于状态提示，不参与装饰。
- 圆角：卡片和输入框最大 `8px`，图标按钮 `6px`，状态标签 `4px`。
- 边框：以 `#DDE1DB` 的 1px 实线区分层级，阴影仅用于搜索下拉和悬浮层。
- 字体：沿用 Geist/系统中文字体；页面标题不超过 `36px`，卡片标题 `16px`。
- 动效：仅保留 150ms 的颜色、边框和轻微位移反馈；移除 3D 倾斜、扫描线、背景动画和光晕。
- 深色主题：保留主题切换能力，但使用中性炭黑和灰色，不恢复紫蓝科幻视觉。

## 页面结构

### 导航

导航采用实色背景和底部分割线。品牌位于左侧，中间提供“工具、场景、排行”文本导航，右侧保留主题、登录和用户入口。图标按钮使用明确的 `aria-label` 和 `title`。

### 首页首屏

Hero 改为紧凑的目录引导区：

- 标题：“按任务找到合适的 AI 工具”。
- 副文案强调具体价值，不使用“一站式”“最佳”等泛化表达。
- 搜索框作为主要交互，桌面显示 `⌘K`，小于 `640px` 隐藏快捷键。
- 收录数量与更新时间作为辅助信息，不再拆成发光统计项。

首屏之后立即展示“本周值得试”工具列表，随后才是场景入口。移除首页“数据概览”，数据保留在排行榜或用户页等更合适的位置。

### 搜索

搜索建议按工具 ID 去重，每个工具只出现一次。建议项展示工具图标、名称和一句描述；下拉使用实色浮层。输入框需要可见焦点样式、清除按钮标签和键盘操作支持。

### 分类与排序

分类使用横向文本标签页，选中态通过下边线和强调色表达，不使用渐变胶囊。排序使用紧凑分段按钮或菜单，保持至少 44px 的移动端点击区域，并提供横向滚动提示。

### 工具卡片

卡片以比较信息为核心：

- 工具图标、名称和一句用途描述。
- 价格、平台、更新时间和最多两个高价值标签。
- 收藏与外链使用熟悉图标，并提供工具提示/无障碍名称。
- 卡片整体可进入详情页；外链与收藏保持独立操作。
- 不使用 3D 倾斜、扫描线、彩色光晕或渐变边条。

真实品牌 Logo 当前数据中不可用，因此本次继续使用统一线性图标，同时通过中性图标底和名称强化识别；后续可在数据模型补充 `logoUrl` 后升级。

### 移动端

- 首页上下边距缩小，搜索和首批内容进入 844px 高的第一屏。
- 底部导航保留四项，使用实色背景并减少视觉高度。
- 分类可横向滚动但不造成页面级横向溢出。
- 所有主要点击区域不小于 44px，文本不得被底部导航遮挡。

## 错误与空状态

- 工具加载时使用中性骨架或简洁加载提示，不显示霓虹动画。
- 无搜索结果时提供清除搜索和推荐分类入口。
- API 失败继续使用现有静态数据回退；两者都失败时显示明确错误文案。
- 收藏、比较和外链跟踪失败不得阻止用户继续浏览。

## 验收

- 运行 Next.js lint、build 和相关仓库检查。
- 浏览器检查首页、工具页、搜索建议和卡片进入详情页。
- 验证桌面 `1440x900` 与移动端 `390x844`，确认无横向溢出、遮挡或首屏空白。
- 检查控制台无相关错误和框架错误覆盖层。
- 截图对比确认第一屏出现真实工具，且不再出现粒子、网格、紫蓝渐变、玻璃卡片和 3D 悬浮效果。
